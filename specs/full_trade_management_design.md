# 外贸报价与单证管理系统设计

## Requirements

- 在浏览器中维护产品、供应商、客户档案。
- 产品支持图片上传、多个供应商报价及历史询价记录。
- 报价单支持多产品、散货/整柜、公共费用、EXW/FOB/CIF 推荐价及人工覆盖价。
- 所有公共费用按报价单产品总数量分摊，商品行合计与报价单总计一致；最后一行使用尾差调整保证金额相等。
- 根据报价单渲染报价单和 PI，并支持浏览器下载 PDF。

## Architecture

- Frontend: Vue 3 + TypeScript + Element Plus + Vite. `App.vue` 负责模块壳，模块页面位于 `src/views/`，`src/services/api.ts` 封装 REST 请求，`src/utils/quoteCalculator.ts` 只负责报价计算。
- Backend: Node.js + Express，统一入口 `server/index.js`，Zod 校验边界输入，Multer 将图片保存到 `uploads/`。
- Database: SQLite via better-sqlite3，启动时创建表和演示数据。产品、供应商、询价、客户、报价单、报价明细、公共费用均持久化。
- Documents: 前端以当前报价单数据渲染 A4 文档预览；使用浏览器打印对话框选择“另存为 PDF”，保留打印 CSS 以满足 PDF 下载场景。

## Quote calculation invariants

- `EXW = 成本价 + 包装费 + 国内运费 + 利润`
- `FOB = 成本价 + 包装费 + 国内运费 + 报关费 + 银行手续费 + 利润`
- `CIF = 成本价 + 包装费 + 国内运费 + 报关费 + 银行手续费 + 海运费 + 保险费 + 利润`
- 国内运费、报关费、银行手续费、海运费、保险费是整单公共费用，按所有产品数量合计分摊到每件。
- 本项目将包装费、利润建模为产品行的单件可编辑数值；公共费用是报价单级总额。
- 业务员输入的单品贸易术语价格覆盖推荐价；未覆盖的价格随成本、费用、数量变化实时重算。
- 金额以分（整数）进行尾差处理，最终一行金额补齐 `报价单总额 - 其他行金额`，避免浮点尾差。
- 散货/整柜会持久化并显示在报价单和单证上；需求未定义两种模式不同的数学公式，因此两者均按上述数量分摊规则计算。

## Security

- API 边界使用 Zod 校验字符串长度、日期、ID、正数金额和数量；未知字段不进入数据库。
- SQLite 查询使用参数化语句。
- 图片仅接受 JPG/PNG/WebP，限制 5MB，并生成随机文件名。
- Express 使用 Helmet、CORS 白名单和基础请求速率限制；生产环境通过 `CORS_ORIGIN` 限制来源。
- 本地单机版本没有登录需求，因此不虚构用户认证；若部署到共享环境，认证和角色授权必须在 API 层补充。
- 删除、更新等写入动作记录到服务端控制台日志。
